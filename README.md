# Veille de sujets — Collectif Tariqa PRO (page publique)

Page d'explication de la **Veille de sujets** : chaque semaine, des sujets de contenu
précis, vérifiés à la source et triés selon ta marque, puis des cartes prêtes à filmer. Le
plugin est **réservé aux membres** et se récupère dans l'espace Circle du Collectif. Ici, on
explique seulement à quoi il sert, comment il fonctionne, et comment on l'installe une fois
membre.

Page : https://collectif-tariqa-pro.github.io/ctp-veille/
